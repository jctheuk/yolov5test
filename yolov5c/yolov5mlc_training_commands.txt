# ===== YOLOv5MLC 模型優勢 (比 YOLOv5m 大，比 YOLOv5l 小) =====
# 1. 模型大小：depth_multiple 0.83 (+24% vs YOLOv5m), width_multiple 0.875 (+17% vs YOLOv5m)
# 2. 參數數量：約 30M 參數 (YOLOv5m: 21M, YOLOv5l: 47M)
# 3. 記憶體使用減少：約 25-35% GPU 記憶體節省 (相比 YOLOv5l)
# 4. 性能平衡：比 YOLOv5m 更強，比 YOLOv5l 更省記憶體

# ===== 實驗一致性設置 =====
# 保持與原始實驗相同的參數配置：
# - 使用 hyp.default.yaml (與原始實驗一致)
# - 移除 --cos-lr (原始實驗未使用)
# - 移除 --amp (原始實驗未使用)
# - 僅通過模型大小優化解決記憶體問題
