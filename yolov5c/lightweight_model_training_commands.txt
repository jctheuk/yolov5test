# 3. 記憶體使用減少：約 25-35% GPU 記憶體節省
# 4. 性能平衡：比 YOLOv5m 更強，比 YOLOv5l 更省記憶體

# ===== 預期記憶體使用 =====
# 原始 YOLOv5l: 31.9GB (99.7% 使用率)
# 中等加強模型: ~22-26GB (69-81% 使用率)
# 比較 YOLOv5m: 約增加 15-20% 記憶體但性能更好

# ===== 性能權衡 =====
# 優點:
# - 顯著減少記憶體使用
# - 更快的訓練速度
# - 更好的數值穩定性
# - 更容易部署

# 考慮:
# - 可能略微降低模型精度
# - 需要驗證醫學圖像任務的適用性
# - 建議與原始模型結果比較

# ===== 使用建議 =====
# 1. 優先使用：適合記憶體受限環境
# 2. 批次大小：可使用更大批次 (64-128)
# 3. 組合策略：輕量化 + 混合精度 + 梯度累積
# 4. 性能驗證：與原始模型結果比較

# ===== 進階組合策略 =====
# 如果仍需要更多記憶體節省，可以：
# 1. 進一步降低批次大小至 32
# 2. 使用更激進的 width_multiple (0.5)
# 3. 結合梯度檢查點 (gradient checkpointing)
# 4. 使用更小的圖像尺寸 (384 instead of 416)
