## 模型配置說明

### 分類模型（Classification）
- **yolov5s_original**: YOLOv5-Small 原始分類模型
- **yolov5m_original**: YOLOv5-Medium 原始分類模型
- **yolov5l_original**: YOLOv5-Large 原始分類模型

### 檢測模型（Detection）
- **yolov5s_SC**: Small模型 + Simple Classification Loss
  - backbone, p3, p4, p5: 不同檢測頭配置
- **yolov5m_MC**: Medium模型 + Multi-scale Classification Loss
  - backbone, p3, p4, p5: 不同檢測頭配置
- **yolov5m_MLC**: Medium模型 + Modified Loss with Constraints
  - backbone, p3, p4, p5: 不同檢測頭配置
